# WiFiNav

连通性感知视觉语言导航研究：在线 RSSI 信号场估计与通信风险规划。

## 当前状态

模型基座已选定为 **Qwen3.5-35B-A3B**，使用冻结权重进行多模态推理。项目处于实施准备阶段，模型尚未部署，完整导航实现尚未冻结，暂无本项目实验结果。

## 下一步

1. 接入服务器，盘点GPU、磁盘、环境和已有项目文件。
2. 部署模型服务，记录实际显存与图文请求延迟。
