# WiFiNav

连通性感知视觉语言导航研究：在线 RSSI 信号场估计与通信风险规划。

## 当前状态

模型基座已选定为 **Qwen3.5-35B-A3B**，使用冻结权重进行多模态推理。服务器盘点、项目同步和模型部署已完成，文本/单图/双图服务验收通过；已有Habitat环境可复用。**具体任务、benchmark改造协议及完整导航实现尚未冻结，无导航实验结果。**
