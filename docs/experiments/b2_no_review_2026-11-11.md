# B2 v1关闭STOP复核消融

## 运行前冻结

沿用全部10任务和3种AP布局，不替换失败。manifest SHA256：`8a0caf14400bd73939c97e976cdc5e97c34ce32eb2da35eee936c53a5dd1d326`。与完整v1仅改变STOP复核开关；保留宽容说明字段解析和ProgressGuard，不改变模型、常规提示、深度候选、几何控制器及预算。

新增 `--stop-review auto|on|off`：auto保持原行为（v0关闭，v1开启），本次显式off。开关写入worker和batch metadata，恢复运行时不允许混用开关。

```bash
cd ~/WiFiNav
/opt/anaconda3/envs/habitat0.3.0/bin/python -u scripts/run_pilot.py \
  --interface-version v1 --stop-review off \
  --batch-dir runtime/batches/pilot_v1_no_review
```

预先判断标准：运行异常不再出现、原成功任务保留、无STOP复核导致的路径/请求增加；仍按全部10条报告SR/SPL和失败。若满足，采用此版本作为B3接口起点，不以此宣称模型导航提升。B3同规划器λ=0还须另行验证。

off的30回放中23个出现断连、29个弱信号，无错误前缀。这些是NoSignal轨迹的通信诊断，未证明选路收益。
