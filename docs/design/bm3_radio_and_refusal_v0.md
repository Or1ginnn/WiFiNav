# BM3无线评测与拒绝通行协议 v0

2026-11-19。依据用户本轮指示：AP布局兼容原指令路线；允许通信风险报告与拒绝通行；最新决定首版限定单层，楼梯/跨层任务暂不纳入新版本。状态：评测规范草案与独立离线参考计算器已实现；AP新生成器、在线预测/拒绝状态机、多层执行/传播尚未实现或验收。本协议不修改旧B3、BM4、原30AP实例或Qwen prompt。

## 1. AP布局与指令路线的关系

新版本优先构建“原指令路线兼容”的受控实例：原指令/终点/参考路径不变，在原路线附近形成局部弱覆盖，让策略有机会选择原路线内的左右通行位置、观察/等待/有限退回，避免主要靠绕到另一房间来取得收益。参考路径、目标与语言约束仅供构建器/离线QA，不传给运行策略。

BM1/BM2在生成前固定AP采样候选、路径邻域与长度预算、关键地标/转向/门口关系的审计规则、seed及失败条件；范围/阈值尚待CPU几何与语义QA冻结。不能仅以欧氏距离接近参考线保证指令合法：相邻门、隔墙、门内外或楼上投影相近仍可能违背指令。几何邻域约束和语言/地标约束分别检查。

这是任务条件化的受控布局分布，不冒称现实随机AP分布；与按预定规则生成的自然集合分开报告。新AP配置与实例另立版本，保留没有局部合法替代路、目标在弱区和覆盖不足的样例/构造失败统计；不读取Ours输出选AP，不将AP放置优化本身当导航算法收益。原start/near/far三个布局不更换。

## 2. 通信风险报告与拒绝通行

在线模块可依据当前/过去测量与可部署预测报告“当前信号弱”“前方预测风险高”或“证据不足”；三者分开。不能把未走区域的真实RSSI或完整场直接给在线VLM来声称提前感知。StaticMap有真值权限，只作额外信息对照并明确标记。

| 状态/动作 | 触发依据 | 本地行为/评分 |
|---|---|---|
| 正常通行 | 当前测量与预定风险规则允许 | 继续原语言任务 |
| 风险告警 | 近期观测/预测，附位置、时刻、来源及置信/不确定性 | 报告依据；可在原路线约束内另选合法局部动作 |
| 局部观察/有限退回/等待 | 风险规则触发、尚有预定预算 | 均计时间与动作；等待不会在静态无线场中自动改善空间覆盖 |
| connectivity_abort | 风险持续、无已知合法替代且有限恢复预算耗尽 | 在可用连接时报告，明确是通信原因退出；不是到达目标的STOP成功 |
| link_lost | 独立链路实验实际发生请求不可用 | 本地控制器执行预定停驻/恢复策略，不能依赖失联后再次远程请求VLM |

上述状态机、风险阈值/确认窗口/重连滞回/退回与等待上限在新实验前写定，目前未接入在线执行。当前Qwen接口只有waypoint/look/stop且不接收RSSI；不能把新的拒绝协议当已经实现的功能，或静默把model_stop改成connectivity_abort。

**允许拒绝不等于拒绝也算导航成功。** 固定全集并列报告导航SR、通信退出率、任务完成率、断连暴露/最长断连、等待/退回/动作/请求开销。一直不动或提前拒绝即使断连为0，也不能在总体评价中胜出。误拒绝分析需先有离线合法/可连通路线证据或可信标注；有一条GT几何路不等于当前在线策略应已知它。

保留原柔性代价设置；“超过风险阈值可拒绝”的设置另立约束任务协议和比较表，所有方法共享相同终止/预算/信息规则。此设计不撤销原方法Go/No-Go，不直接启动Online Belief训练或实现。

## 3. 无线评价的版本化决定

新开发评测以**latent信号场阈值暴露**作为主要物理代理；含测量噪声的阈值事件作为观察侧辅助指标。运行策略仍只能得到允许的含噪观测，评价器看到truth不构成actor权限。旧B3按动作终点measured标签计算的指标继续保留，不和新口径合并排名或回写历史结果。

独立参考实现：`src/connectivity_vln/evaluation/radio_metrics_v1.py`。输入已记录位姿/运动时间轨迹和仅评测可用的truth回调；相邻位姿按3D分段线性插值，每个动作区间分成不超过.1s的小区间，在中点查询、按dt积分。它是轨迹重建近似，不是连续物理真值。正式配置保存实际积分步长与阈值，并以.05/.1/.2s检查敏感性再冻结BM5设置。模型推理等待默认不计该运动时间指标，另报wall time；链路/等待实验必须另有统一时间轴。

- 弱信号与outage阈值区分，默认沿用当前配置-67/-75dBm作为开发假设，不是普适掉线阈值。等于阈值时不计低于阈值。
- 前进和转向均计时，STOP零时长不创造断连事件；同一连续outage跨动作边界合并。
- 回调缺失或非有限值时主要暴露统计标为不可用，不当真实0；零时长轨迹比例为null。
- 完整终止与错误前缀分别标记；错误前缀不能作为完整轨迹通信比较结果。
- 3D插值仅表示评价器保留高度，不代表现有2D SignalField已经变成多层传播模型。原场仍按XZ距离与二维阴影查询；新多层无线需高度/楼板/跨层参数与独立验证，不用2D投影冒充。

初始9项合成测试覆盖穿越弱区、转向/STOP、跨动作连续性、缺测、错误前缀、零时长、严格阈值、高度传递和非法参数；它们证明积分与缺测逻辑，不证明真实传播、在线拒绝或多层导航。

## 4. 最新范围决定：单层先完成，多层后置

用户已明确首版只做单层。上下楼/跨层任务本身仍合法，但不在新的单层派生版本范围内；BM1在新策略运行前固定范围规则，核查语言、参考路径/目标与几何，记录歧义及排除原因/数量/比例，不以模型成败过滤。

原任务97及所有旧B3/BM4记录保留；既有30case开发schema原型也不回写。新排除清单尚未生成，不将其写成已完成。当前单层规划器/2D信号场继续保持已声明边界，不因本轮决定改动高度检查。

楼梯几何诊断、3D/分层图、多层目标执行及高度/楼板传播移至后续版本；不作为本轮前置工作。当前顺序是单层范围与清单 → 路线兼容AP → 单层通信风险决策与评测，机制逐项验证，旧结果不变。

## 5. 成熟传播模型与 AP 选点试点

将“反推 AP”暂按离线覆盖设计理解。先指定要稳定覆盖的路线或诊断所需的局部弱区，再比较有限的合法 AP 候选位置。AP 定位是从观测 RSSI 估计现有 AP 的另一项任务。首轮保持单层、每套布局一个 AP。

- 现有对数距离和 navmesh 绕行模型用于低成本候选扫描及复查历史结果。用 [Sionna RT](https://nvlabs.github.io/sionna/rt/tech-report/) 在小范围独立生成射线追踪覆盖，检查候选 AP 和路线的覆盖排序对传播模型是否敏感。[ITU-R P.1238](https://www.itu.int/rec/R-REC-P.1238-13-202509-I/_page.print) 用于查找室内传播和材料损耗的参考范围。具体频率、设备参考功率和材料假设在试点运行前登记。
- 固定首个开发试点为当前 20 条审阅任务中的 `2n8kARJN3HM` 同层 121、134、235、512。AP 候选用这四条已有初值在 X–Z 平面相距最远的一对，对应 235 和 512 的初值。四条路线各评价两个布局，共八个组合；这个配对由坐标确定。记录相同的 X–Z 采样位置、物理收发高度、坐标变换、材料参数、频率、功率、计算时长与缺测。两个模型以同一布局实例配对评估。
- 首轮检查两种传播模型给出的候选 AP 排序、参考路线上弱区的位置和长度、起止点覆盖和断连分类。备选路线先核对经过的门、地标和顺序，再比较原路与备选路线的覆盖。材料不确定时使用预先记录的多个材料假设检查结论是否稳定。冲突与证据不足保留为诊断结果。正式自然集仍按预定规则布点；按任务目标覆盖反推的布局归入受控诊断。
- 服务器资产已读核查。五个场景都有 GLB 与 navmesh，试点另有 `.house` 和语义 PLY。GLB 的材料表是渲染材料，试点 148 项均无附加射频参数。射线追踪试点需记录材料映射及其适用范围，射频材质与收发配置仍需确定；当前 Habitat 0.3.0 环境未安装 Sionna、Mitsuba 和 Dr.Jit，后续试点应放独立环境。已在独立环境生成 2.437 GHz 试点地图。两种材料下仍有不一致的断连分类，因此现有轻量模型用于开发主线，射线追踪作独立核查。见[传播模型试点记录](../experiments/rss_propagation_pilot_2026-11-19.md)。

真实场景验证另行记录。若要主张 AP 选点可迁移到实际 Wi‑Fi，先用一部分定点 RSSI 测量校准，再用留出的路线复核排序与低信号区。应用若关心真实掉线，还需同时记录丢包或请求成功率。开发用 −75 dBm 阈值继续作为可复现的仿真假设。
