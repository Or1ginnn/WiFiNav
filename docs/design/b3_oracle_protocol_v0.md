# B3通信规划首轮协议

2026-11-11，运行前固定。配置：`configs/benchmark/oracle_smoke_v0.json`。

## 进入条件与边界

先完成B2关闭STOP复核消融，检查保留原成功任务且无运行异常。冻结Qwen、原指令、候选点生成与动作预算；没有导航权重训练。新增已知几何单层navmesh栅格规划器，原navmesh控制器只作为历史工程基线。

统一Dijkstra图：分辨率0.25米，节点snap水平误差≤0.03米、相对起点层高误差≤0.20米。8邻接边与端点连接通过双向navmesh try_step中点/终点检查，不允许穿墙或自动回退到不同规划器。楼梯、跨层、栅格不连通失败必须保留。完整几何权限对NoSignal与StaticMap一致，不宣称未知地图导航。

边代价为 `length * (1 + lambda * mean(endpoint_risk))`。风险是静态真值RSSI在弱信号与断连阈值之间的线性截断值[0,1]；不读取未来测量噪声。λ=0不调用任何信号风险查询。StaticMap仅向低层规划器增加信号真值权限；模型仍只见原视觉、指令、有限历史和动作反馈，不见AP/目标/参考路径/风险图。

局部终点仍由模型产生，最大1.5米；通信路线可能因该视野/执行预算限制而没有绕行空间。先检查这一限制，不因Oracle无收益增加模型或训练。

## 三层检查

1. **合成双路径测试**：短路穿过弱区，长路信号良好。验证λ=0不读信号，λ=4可选择长路，并报告额外路程；断图明确报错。此测试只证明代码行为。
2. **固定局部目标离线诊断**：B2无复核批次全部10任务，每条按日志顺序取前2个已记录局部目标（不足则如实记录），跨原3布局与λ={0,1,4}。起点为该决策执行前实际位置，终点固定，检查可规划性与静态真值断连长度，记录所有失败。该诊断读取已记录目标，不是在线VLN，也不报告SR或真实动作耗时收益。
3. **闭环接线检查**：从原manifest按顺序取每个scene首条任务，即515与85；选择不依据结果。两个任务各运行一次λ=0并回放三布局；StaticMap对全部三布局各跑λ=1、4，共14次实际执行、18个case行。每种λ有2个语言任务/6个布局case，布局不是独立语言样本。此阶段是B3 smoke，不能替代完整10任务/30布局验收。

## 判断与记录

- 原始失败、提前停止、无进展、超时和不连通都保留；不得根据结果替换任务/AP或只报告成功case。
- 同时报告SR/SPL/nDTW、路径长度、动作数、模型请求、运动时长、断连时长/比例/最长断连与额外实际耗时；按λ、任务、布局配对展示。
- 成功条件与全部任务分别检查；不能把提前失败的短轨迹当通信改善。
- 若λ=0栅格控制器发生明显几何退化，先解决共同执行器，不能归因于无线代价。
- 若仅合成测试有效，实际局部目标无通信绕行空间，记录受限原因；不直接扩大belief或宣称Go。
- 接线正常且有可解释通信—导航权衡后，继续全部10任务×3布局的正式B3开发验收；之后才扩大在线belief。2任务smoke不足以证明总体收益。
