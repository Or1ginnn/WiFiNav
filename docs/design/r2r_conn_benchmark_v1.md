# R2R-Conn首版任务卡与构建规范 v1（BM0）

日期：2026-11-19。状态：任务定义/信息权限卡已形成，供BM1–BM3落实；不是已生成或可发布的正式benchmark。已采纳范围以根plan为准。本文更新v0的任务与构建定义，旧实验/冻结配置不变；正式资格阈值、清单、采样/评分参数和发布许可尚未全部闭合。

## 1. 要评估什么

在保留R2R-CE原语言指令与导航成功定义的条件下，机器人沿途获得RSSI观测，衡量完成导航时的通信暴露及额外路径/动作/推理代价。任务不承诺每个实例都存在通信改善空间。benchmark保留合法单层与楼梯/跨层任务，采用已知几何辅助、理想位姿、单AP无线扩展；当前实现证据只覆盖单层2D代理，跨层执行与传播须独立验收，不宣称已具备完整多层能力。

原指令/起终点/参考路径不改写。经过的地标、先后顺序、左右/相对位置仍属于指令内容，不能用“同终点”代替遵循指令。源SR/SPL/nDTW并列报告，但SR不能认证全部语言约束，nDTW也不是语义真值。开发指令的文本/几何冲突标注用于诊断，不作为新成功真值或正式选样依据。需要“允许绕行且保留部分地标”的新指令任务时另立版本和人工标注验证。

## 2. 分离benchmark规则与参考导航器

| 层 | 首版设计/现有基线 | 是否要求所有参评方法相同 |
|---|---|---|
| 源任务与评测 | 同一版本源任务、固定manifest/split、原指令/终点与评测预算 | 是；正式配置在BM1/BM3冻结 |
| 几何/位姿权限 | 已知导航几何、理想位姿；任务可含楼梯，各执行器能力单列 | 是；不能某个方法额外获GT终点/参考路径，也不因当前单层限制判跨层任务无效 |
| 无线信息 | NoSignal不读取无线；Reactive仅当前观测；Online Belief仅截至当前的观测；StaticMap额外读静态完整无线场 | 按方法定义区分并显式登记 |
| 视觉/深度 | 参考基线448×448、90°视场、RGB-D；配置及模态/历史用量记录 | 主比较需一致模态/观测预算；额外模态另列设置 |
| 原始动作 | 参考设置前进.25m、转向15°、STOP、500动作上限，STOP计步 | 主track动作与预算在BM3统一锁定；不得漏计局部控制器动作 |
| Qwen工具层 | 深度候选→waypoint/LOOK/STOP，最多80次决策、每次最多2次解析、有限记忆、STOP复核off | **不是benchmark必备接口**；其他方法可独立实现合法策略，报告调用/开销与统一原始动作预算 |
| 局部规划器 | 当前共享.25m栅格，起点层高±.20m；1.5m局部目标、有限执行/无进展退出 | **是参考基线限制**；不能据其短路径空间定义整个benchmark机会，也不要求所有方法采用同一规划范围 |

同一参考导航器的NoSignal/StaticMap必须共享几何规划器、执行器和预算，λ0只去掉无线代价。比较不同导航器时另外报告架构/观察/计算预算差异，不能把更强导航器改进归给通信机制。Qwen模型/revision/精度在当前工程回归中固定，不因benchmark接口独立而新增模型选型。

## 3. 输入、输出和真值访问

| 模块 | 可访问 | 禁止或用途限制 |
|---|---|---|
| Qwen策略 | 原指令、当前RGB/有限历史、当前深度候选、有限反馈/记忆 | 不见GT目标/参考轨迹/评估分数、AP坐标或完整无线场 |
| 在线导航/无线模块 | 与对照一致的几何/理想位姿，按模块定义的当前/历史RSSI | 不见未来观测、完整无线场、GT终点或参考路径；几何可用不等于终点已知 |
| StaticMap低层 | 同几何、模型给出的局部目标、完整静态无线场 | 不从GT目标/参考路径推导导航子目标；不声称真正全局最优VLN Oracle |
| 构建器/QA/离线诊断 | 源目标/路径/场/AP配置，用于资格、分层、路线空间诊断 | 不能把这些诊断结果喂给actor或按某模型成功挑样 |
| 评测器 | 完整任务真值、真实轨迹、完整场和退出/日志 | 仅离线评分；actor和评分载荷/通道分离 |

actor返回合法导航动作或STOP；规范不要求特定VLM候选ID。发布接口需将公开任务输入与受保护评估真值分开，而不是把包含goal/path/AP的完整manifest直接传给策略。源码级“未传入”是当前审计方式，不宣称已实现对恶意策略的系统隔离沙箱。

## 4. 成功、失败与评分合约

现有Habitat0.3.0的Success实际逻辑是调用STOP且distance_to_goal严格小于配置阈值；本项目参考阈值3m。源目标、navmesh距离、成功配置与GT参考hash须一起记录，不能只看episode字段goal.radius或仅凭终点欧氏距离。SPL来自同次env指标，nDTW采用精确Euclidean DTW，连续重复位姿去重、以GT参考点数×成功距离归一化；正式发布前固定官方实现commit与parity用例。

| 结果 | 必须保存 | 评价约束 |
|---|---|---|
| STOP成功/STOP失败 | 全轨迹与源导航指标、通信/动作/请求开销 | 成功不等于所有语言约束已人工验证 |
| 动作/决策预算耗尽、正常无进展 | 完整终止失败、实际已执行轨迹/开销 | 不从全样本分母删除；不凭较短暴露声称收益 |
| 工具错误/崩溃/timeout | 错误原因、前缀、已记录动作/请求、完整性标志 | 错误前缀不能当完整轨迹通信胜出；缺测以null/不可用标记，不填真实0 |
| 缺产物 | case身份、missing状态、可追溯日志 | 不静默省略case；评测完整性未通过 |

固定完整任务全集报告导航与通信并列结果；按source-scene/source-path聚类，AP布局不作为独立语言样本。baseline成功配对子集和各方法成功子集只作注明分母的辅助分析。暂不设事后加权联合分数；跨模型排序、导航损失与绕行约束在BM3/BM5运行前写定，原B3门不直接变排行榜。

## 5. 无线、时间与集合

当前route_a是XZ距离损耗+navmesh绕行遮挡代理+.5m分块阴影+动作index观测噪声；不称3D传播、实墙损耗或平滑随机场。现pilot用-48dBm@1m、指数2.8等覆盖原始路线A默认配置，需保存每实例实际配置，不能只引用基础JSON。StaticMap规划风险查latent truth，现回放通信标签基于measured值，两者不同。

现基线前进时长1s、转向15°为.5s，STOP零运动时长；每原始动作取一个终点RSSI并将标签赋给该时间段。模型等待不计入运动暴露。此为历史离散测量阈值代理，保持旧结果；BM3必须选择并冻结新版本的时间/空间积分、truth与含噪声评分、噪声耦合与缺测规则，并做采样敏感性验证。不得混版本比较或直接解释为真实请求失败。

- **自然任务集合：** 预设策略无关生成/QC，报告好覆盖、弱区、起终连通、长度、楼层与可选路线属性；start/6m/12m是半径规则，不能直接充当覆盖等级。不筛成所有样本必有收益。
- **受控诊断集合：** 显式构造双路径/无线对比，用于检测机制或接口是否能选出不同路线；独立报告，不能当自然集泛化证据。
- **任务有效性与执行器能力分层：** BM1结合源路径/目标/语言/几何记录楼层变化与有效性，另记执行器是否支持。上楼本身不是无效或必排除理由；支持子集与总体覆盖率分报。参考点或目标同高不证明全路线同层。
- **划分：** 开发只用train；源val_unseen为保留候选，scene/path group隔离。未冻结前不对保留集做策略运行/阈值调优。当前10任务始终作为旧开发集保留，不按新资格删改原B3。

## 7. 本轮范围修正与无线协议

用户明确提出上楼可做，因此“仅单层”收缩为现有参考执行器的证据边界，不再作为benchmark总体的任务排除规则。当前floor网格与像素目标同层约束需新执行能力诊断；既有代码/旧失败不改。新增[BM3无线与拒绝协议](bm3_radio_and_refusal_v0.md)定义原路线兼容AP的受控构造、风险报告与connectivity_abort、独立latent暴露评分。它们是新版本开发规范：在线拒绝/前方预测/跨层传播尚未实现，不把拒绝计到达成功，不将完整场给在线策略。
