# 4×4090 本地 Zero-shot VLN 可行性

日期：2026-11-03。用户报告可用4张RTX4090、合计96GB显存；服务器尚未连接，不能视为硬件实测。是否同机、GPU空闲、PCIe拓扑、CPU内存、驱动与数据访问待核实。

## 结论与使用边界

不用付费第三方API与zero-shot兼容。预训练模型可部署在自有服务器，冻结权重推理，在线belief通过RSSI更新。接口可以是自托管HTTP服务；“不使用API”在此指不使用外部按量收费的模型服务，并非禁止程序接口。

4×24GB是分布在4张卡上的显存，不是单卡96GB。跨卡模型需框架支持分片/并行，运行速度还受卡间通信影响。下面只有容量估算，未运行任何模型或导航episode。

| 模型规模 | BF16纯权重粗估（不含缓存与工作空间） | 当前硬件下的建议 |
|---|---:|---|
| Qwen3-VL-8B | 约16–18GB | 控制图片和上下文后可尝试单卡；需要更多余量时使用两卡或量化 |
| Qwen3-VL-32B | 约64–68GB | 四卡分片具有容量可行性；量化后可释放显存给感知与仿真 |
| Qwen3.5-35B-A3B | 约70GB级 | 四卡分片或量化是可评估方案；MoE须存放全部专家权重，不能按3B计算存储 |
| Qwen3.5-122B-A10B | BF16约244GB级 | 不作为起步目标；即使4-bit可压缩权重，96GB同时容纳完整导航栈的余量也需严格验证 |

估算依据为参数规模×每参数字节数，并非厂商实测最低配置。视觉模块、KV/其他状态缓存、长上下文、多图、CUDA图、并发和仿真都额外占用显存。模型来源：[Qwen3-VL-8B](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)、[Qwen3-VL-32B](https://huggingface.co/Qwen/Qwen3-VL-32B-Instruct)、[Qwen3.5-35B-A3B](https://huggingface.co/Qwen/Qwen3.5-35B-A3B)。

## 已核实的方法与代码状态

| 方法 | 本地/zero-shot证据 | 目前限制 |
|---|---|---|
| Open-Nav（ICRA2025） | [作者仓库](https://github.com/YanyuanQiao/Open-Nav)提供开放模型VLN实现、R2R-CE100子集说明和运行入口 | 包含已有训练的waypoint predictor和视觉编码器。可以不追加训练，但不能声称所有模块均无导航训练；原环境较旧，仍需安装验证 |
| EmergeNav（2026预印本） | [原论文](https://arxiv.org/html/2603.16947v1)报告Qwen3-VL-8B/32B、无任务专用训练、无独立waypoint predictor | 本轮没有确认完整公开代码；论文主张不等于已具备可直接运行的仓库。无显式地图/图搜索，接通信costmap需要额外接口设计 |
| SpaceVLN（2026预印本） | [论文表7](https://arxiv.org/html/2606.08992v1)报告本地开放权重组合 | 原组合含122B规划模型；[项目页](https://charles-donne.github.io/SpaceVLN/)目前仍显示准备中。不能认定已有可直接复现的完整实现，也不能将换成小模型的结果视为原配置结果 |

## 适合项目的部署方式

```text
机器人/仿真客户端 --WiFi或受控链路--> 自有GPU服务器上的冻结VLM
       |                                      |
       +---- RSSI belief + 连通代价 + 规划 <----+ 子目标/决策结果
```

可以只依赖局域网而不依赖互联网或商业模型API。自有服务器是远端推理节点，机器人与服务器间仍然存在通信需求，能够保留项目的连通性研究设定。需要明确实时控制、belief、缓存子目标及推理超时逻辑分别运行在哪里；只有经过验证的任务服务中断才可计入应用层失败。

若使用同一服务器上的Habitat客户端模拟网络，链路影响须显式注入实际请求流程；主方法和对照共享映射及预算，避免直接查未来信号真值。

## 下一步建议（尚未部署）

1. 连接服务器后核实4张卡与可用显存、驱动、PCIe拓扑和主机内存。
2. 先加载开放8B VLM做少量图文/结构化输出推理，测显存和延迟；这只验证模型服务，不能替代VLN成功率实验。
3. 审计可运行的完整VLN系统及通信代价接入点，记录导航训练背景；先复现其原始NoSignal配置，再做模型替换。
4. 根据8B基线结果决定是否上32B或35B量化模型；所有组固定相同模型、观测和任务预算。
5. 付费API退为可选对照；使用本地推理仍有电力、服务器占用和维护成本，不宣称整个实验零成本。
